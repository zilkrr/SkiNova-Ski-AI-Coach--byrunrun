# Ski Pro 内容与 SEO 学习案例

状态：本地作品样例；没有已验证的搜索排名、自然流量或外链成效。英文内容为 AI 辅助草稿，尚待本人编辑和滑雪专业人员审核。

## 用户与搜索意图假设

目标用户：希望记录练习、准备教练反馈的英语滑雪初学者。以下关键词是基于产品场景提出的种子词，未取得 Ahrefs/Semrush 搜索量或难度数据，不能称为已完成完整关键词调研。

| Cluster | 种子词 | 意图 | 页面/行动 |
|---|---|---|---|
| Video review | how to film skiing / ski video feedback | 信息型：怎样拍有用的片段 | /guides/how-to-film-skiing → 上传检查 |
| Training log | ski training journal / ski progress tracker | 信息型与工具型：怎么记录进步 | /guides/ski-training-journal → 写日志 |
| Practice planning | beginner ski practice plan | 信息型：怎样安排练习 | /guides/beginner-ski-practice-plan → 创建计划 |

## 已落地

3 个英文服务端文章页面；独立标题、description、H1、内容结构和相关内链。设定真实 public URL 后可生成 canonical、sitemap；本机默认 noindex。没有批量生成低信息量模板页，也没有宣称 schema 或 GEO 能保证曝光。

## 下一步做真实验证

1. 在可访问的公开域名部署经过审稿的内容；为服务补账号、配额与运维控制。
2. 自己验证 GSC 站点所有权、提交 sitemap、检查索引；当前没有做这些操作。
3. 用 Ahrefs/Semrush 等实际检索种子词，保存日期、国家、搜索量、KD、SERP 特征；记录前三个自然结果的 URL、意图与内容缺口。没有账号时可以先人工检查公开 SERP，但不编造工具指标。
4. 每两周用相同时间长度和筛选条件导出 query 数据，导入本工具，筛选优先检查项；查看落地页和 SERP 后再决定改标题或补内容。
5. 当前建议规则只是 >=100 曝光、CTR<3%、位置<=20 的演示阈值。CTR 必须按总点击/总曝光计算，平均位置按曝光加权；不把相关性直接称为因果提升。

## PAA / GEO / 外链：准备方案

- PAA：记录真实搜索中出现的问题及日期，再决定是否写入可见问答；当前没有采集 PAA 数据。
- GEO：清楚解释产品能力与限制，给出可核查来源和清晰作者/审稿信息；不承诺被生成式搜索引用。
- 外链：优先分享有帮助的录制/日志模板，寻找相关滑雪社区的资源板块，遵守社区规则。记录来源页、目标页、相关性、follow/nofollow/sponsored、发现/失效日期。没有实际联系、发布或获得外链。
- 竞品：先比较手工日志、视频回看与智能教练三类解决方案；填写实际产品名称、体验日期、截图、用户任务和差异。当前不把设想写成已完成竞品研究。
