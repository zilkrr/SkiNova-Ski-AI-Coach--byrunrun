Ski Pro is now a full-stack app.

Open a terminal in this project directory, then run:

python3 -m uvicorn app.main:app --host 127.0.0.1 --port 8765

Visit http://127.0.0.1:8765 to use the app.

The original standalone HTML is preserved in legacy/index.html. GitHub Pages alone cannot run this Python backend. See README.md for setup and limitations.
